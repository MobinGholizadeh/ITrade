## Activation prerequisites

1. Add the intended public wallet addresses and Alchemy/Helius server access, or a Kraken key that passes the read-only validator.
2. Configure a real VAPID contact, enable a browser/device subscription, and test an actual alert with the dashboard closed.
3. Supply licensed institutional-flow access, an entitled FMP key and optional CryptoPanic/CoinGecko keys.
4. Choose a hosting target/domain, supply an operator login and production secrets, deploy Compose/Caddy, and verify TLS/login. Configure an off-machine backup destination and schedule on that host.

Run `npm run check:readiness` for a secret-free configuration report. Setting presence does not certify a live connection. The local web app and worker are running; no public deployment was performed.

## Calculation and research boundaries

Portfolio 24h attribution reprices today's quantities using venue reference prices; it is not cash-flow-adjusted account performance. Historical snapshots include transfers/balance changes. Cost basis stays unknown unless supplied. Forward alert observations measure price movement, not execution-aware backtest profit. Related-coverage matching highlights candidates and potential conflicts; it does not certify independent verification. Missing data stays unavailable. This is a single-user, read-only spot research application.
